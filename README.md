# גמרא לכיתה ז' – בבא מציעא ע"ו (עיון) ותענית ב–ח (בקיאות)

אתר לימוד סטטי (HTML/CSS/JS, בלי שלב בנייה), בעברית ומימין לשמאל, מותאם לטלפון ועובד גם בלי אינטרנט (PWA).

- **עיון:** בבא מציעא ע"ה ע"ב – ע"ו ע"ב ("השוכר את האומנין"). שורה אחר שורה, עם פשט, רש"י, תוספות, מילון ארמית, מהלך הסוגיא ותרגולים (הבנה, מי אמר, סדר הסוגיא, שקלא וטריא, תרגום ארמית, הסבר סברה, נכון/לא נכון).
- **בקיאות:** תענית ב ע"א – ח ע"ב. לכל עמוד יש סיכום, נושאים, "מי אמר", טקסט מנוקד, שאלות ומעקב חזרות.
- **חזרה:** כרטיסיות בשיטת לייטנר (5 תאים), מבחן חזרה מעורב, והתקדמות שנשמרת ב-localStorage עם אפשרות ייצוא וייבוא בקובץ JSON.

מקור הטקסט: [ספריא](https://www.sefaria.org) (William Davidson Edition). שמות קדושים בפסוקים מוחלפים בכינוי.

## כלים
- `python3 tools/bm_source.py` – בונה את `data/bm76.json` ומאמת כל מילה מול ספריא.
- `python3 tools/taanit_source.py` – בונה את `data/taanit*.json` ומוודא שכל ציטוט ושיוך קיימים בקטע שאליו הם מפנים.
- `python3 tools/check-content.py` – בדיקת כללי תוכן: בלי שם ה' מלא ובלי אמוג'י של אנשים.
- `python3 tools/build-sw.py` – כותב את `sw.js` עם VERSION חדש.
- `node tools/serve.mjs` – שרת מקומי.
